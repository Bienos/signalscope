# SignalScope logo assets

Use only the canonical assets below in the web application:

- `signalscope-wordmark-on-light.png` — teal symbol and navy wordmark for white, canvas and pale surfaces.
- `signalscope-wordmark-on-dark.png` — teal symbol and white wordmark for navy and other dark surfaces.
- `signalscope-mark-teal.png` — compact transparent symbol for browser, manifest and structured-data identity.

The wordmarks preserve the approved artwork and were cropped to the same 520×150 production canvas. The compact mark is a crop of the approved transparent dark-surface wordmark. Do not use the source files with baked-in checkerboard, white or black backgrounds over arbitrary interface surfaces.
